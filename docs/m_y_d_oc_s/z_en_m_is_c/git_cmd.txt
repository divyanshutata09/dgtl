To initiate git for new project
1. git init
2. git add . # {. = all files}
3. git commit -m  "commit message"
4. git branch -M main
5. git remote add origin https://github.com/divyanshutata09/dgtl.git
6. git push -u origin main


Regular Steps:
1. git add .
2. git commit -m "commit message"
3. git push
